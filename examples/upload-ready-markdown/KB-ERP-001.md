# Sales order to production order

A sales order records customer demand. A production order converts confirmed demand into a manufacturing execution plan. In an ERP-MES integration, the ERP system usually owns customer demand, pricing, and delivery commitment, while MES owns shop-floor execution, reporting, and exception feedback.
