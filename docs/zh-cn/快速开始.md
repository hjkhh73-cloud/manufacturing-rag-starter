# Manufacturing RAG Starter 快速开始

这个项目的目标是：把制造业场景中的 ERP、MES、WMS、APS、BOM、MRP、质检、交付、财务经营分析等知识，整理成适合导入 Dify、AnythingLLM 或自建 RAG 系统的知识库格式。

## 适合谁使用？

- 制造业数字化顾问；
- ERP / MES / WMS 实施人员；
- 想做企业知识库和智能客服的 AI 工程师；
- 想把 SOP、项目方案、异常处理经验沉淀成 AI 助手的团队。

## 本地运行

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m mfg_rag_starter build --input data/sample_knowledge.csv --output examples/manufacturing_kb.jsonl
```

## 推荐导入流程

1. 先把业务知识整理到 `data/sample_knowledge.csv` 类似的结构中；
2. 执行构建命令生成 JSONL；
3. 在 Dify 或 AnythingLLM 中创建知识库；
4. 上传或转换生成的知识内容；
5. 使用 `examples/sample_questions.md` 中的问题测试回答效果。

## 注意事项

- 不要上传客户敏感资料；
- 不要上传真实合同、报价、账号、密码、API Key；
- 如果用于招投标、财税、合规场景，必须人工复核。
